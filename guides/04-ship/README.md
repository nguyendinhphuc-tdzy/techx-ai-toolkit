# Giai đoạn 4 — Ship

Nội dung chi tiết đang được bổ sung. Trong lúc chờ, dùng trực tiếp:
`skills/production-readiness/SKILL.md`.

Chủ đề dự kiến triển khai tiếp ở đây: giải thích dễ hiểu về biến môi trường, CORS, rate
limiting, domain/DNS cơ bản, cách đọc log lỗi khi deploy thất bại, giám sát cơ bản sau
khi lên production (uptime, lỗi runtime).
