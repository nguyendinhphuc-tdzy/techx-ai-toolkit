# Giai đoạn 2 — Build

Nội dung chi tiết đang được bổ sung. Trong lúc chờ, dùng trực tiếp:
`skills/ai-solution-design/SKILL.md` và `skills/ai-assisted-build/SKILL.md`.

Chủ đề dự kiến triển khai tiếp ở đây: so sánh AI coding assistant vs AI builder không
code, giải thích Git/version control cho người mới, cách viết prompt hiệu quả có ví dụ
trước/sau, các khái niệm kiến trúc cơ bản (frontend/backend/database/API) giải thích dễ
hiểu cho người không chuyên kỹ thuật.
